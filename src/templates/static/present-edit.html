        How it works

        A presentation is a set of pages. Each page can show one image or video, play an audio track, show text, and offer buttons that lead to other pages. A page can also move on by itself with a timer, or jump somewhere straight away based on a condition.

        You can build everything in the Visual tab, write it as text in the Script tab, or mix the two. Both edit the same presentation. Remember to Save (Ctrl+S). Use ▶ This page to test from the page you're editing. Previews show your variables in the top-left corner.

        Quick start

        • Upload your media in the left sidebar. Uploading a single file while a page is selected puts it on that page.
        • Type the page text, then add buttons. A button with no destination goes to the next page in the list.
        • A page with no buttons and no timer gets an automatic Continue button, so a plain slideshow needs nothing extra.
        • Tick End page on your final page(s). Running past the last page also ends the presentation.

        Destinations

        WriteMeaning
        part2Go to the page named part2
        a, b, cPick one of these at random
        ending*Pick a random page whose name starts with “ending” (the current page is skipped if there are others)
        nextThe next page in the list (same as leaving it blank)
        endFinish the presentation

        Media and audio

        • Media is one image (webp, png, jpg, gif, avif) or video (mp4, webm, mov). Videos loop unless you choose play once.
        • Audio (mp3, ogg, wav, m4a, flac, opus) keeps playing across pages until another page picks a different track, or picks Stop audio. That makes background music easy: set it once on the first page. For a voice-over per page, give each page its own track.
        • A timer set to media moves on when the page's video finishes, or its audio if it has no video.

        Timers

        30 waits 30 seconds, 10-20 waits a random time in that range, 2m waits two minutes and media waits for the video/audio to end. A countdown bar is shown unless the timer is hidden. A timer can sit next to buttons, so the viewer can choose before time runs out.

        Variables

        Variables remember things while someone plays: a score, a name, a choice they made. Give starting values in Settings → Variables. Change them when a page opens, when a button is pressed or when a timer fires:

        score = 0            set to a value
score += 1           add (also -=, *=, /=)
name = "Sam"         text goes in quotes
lives = lives - 1; score = score * 2      several at once, separated by ;
roll = random(1, 6)  a random whole number

        Show a value in page text or a button label with braces: You have {score} points. Anything inside braces is worked out, so {score * 10} works too.

        Conditions

        Conditions decide whether a button is shown, or whether a page jumps somewhere as soon as it opens (a jump). Jumps are checked top to bottom and the first one that matches wins. A jump with no condition always happens.

        score > 5
score >= 3 and lives > 0
name == "Sam"          (a single = works too)
not visited(secret)
visits(intro) >= 3
chance(25)             true 25% of the time
        FunctionResult
        random(a, b)Whole number from a to b. random(6) is 1 to 6
        chance(p)True p% of the time
        pick("x", "y", …)One of the values at random
        visited(page)Whether the page has been shown this playthrough
        visits(page)How many times it has been shown
        min max abs round floor ceilThe usual maths

        A variable that was never set counts as 0.

        Script format

        Each page starts with == name. Lines starting with a keyword set things up; every other line is page text (a blank line starts a new paragraph, and **bold** and *italic* work). Start a text line with \ if it would otherwise look like a keyword. Lines starting with # are comments.

        # Variables and start page come before the first page
var score = 0
var name = "friend"
start: intro

== intro
media: intro.webp
audio: theme.mp3 loop
Welcome, {name}!

Pick a door.
button: Left door -> left
button: Right door -> right [set score += 1]
button: Surprise me -> left, right
timer: 30 -> left

== left
video: hallway.mp4 once
timer: media -> reveal

== right
set: score += 2
if score > 5 -> reveal
The door is locked. You have {score} points.
button: Try again -> intro [if score < 10]
button: Give up -> end

== reveal
audio: stop
You made it with **{score}** points.
end
        LineWhat it does
        media: file (or image: / video:)The page's image or video. Add once to stop a video looping
        audio: fileStart an audio track. Add loop to repeat it. audio: stop silences it
        set: name = valueChange variables when the page opens
        if condition -> destinationJump straight away if the condition is true
        goto: destinationAlways jump straight away
        button: Label -> destinationA button. Optional [if …] and [set …] at the end
        timer: 10 -> destinationMove on automatically. Optional [hidden] and [set …]
        endThis page finishes the presentation

        Playing

        Viewers press Begin to start, which lets the browser play sound. Number keys 1–9 press the matching button. The corner controls mute, restart or exit.
